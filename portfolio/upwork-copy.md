# Upwork Portfolio and Project Catalog Copy

## Portfolio item

### Title

Spring Boot E-commerce Inventory REST API with Tests

### Role

Java Backend Developer

### Description

Built a self-initiated Spring Boot portfolio demo for managing e-commerce products and inventory through REST APIs. The backend supports product creation, SKU validation, inventory updates, duplicate prevention, structured error responses, and MySQL persistence. I added request validation, optimistic locking, OpenAPI documentation, Docker support, and automated integration tests. Deliverables include complete Java source code, API examples, a database schema, tests, and setup instructions. This is a reproducible portfolio demonstration, not client work.

- MySQL

## Project Catalog service

### Title

You will get a diagnosed and fixed Java or Spring Boot backend issue

### Summary

I will investigate and fix a focused Java or Spring Boot backend problem. I reproduce the issue where possible, identify the root cause, implement a maintainable fix, and verify the affected behavior with targeted checks or automated tests. Suitable tasks include failing REST endpoints, request validation, database integration, JPA issues, build or configuration errors, and small backend defects.

### Client requirements

1. A concise description of the expected and actual behavior.
2. Sanitized source code or repository access for the affected module.
3. Error messages, logs, and reliable reproduction steps.
4. Java, Spring Boot, build-tool, and database versions.
5. The acceptance criteria for considering the issue resolved.

### Exclusions

The packages do not cover a full application rewrite, unknown production incidents without reproducible access, security penetration testing, infrastructure administration, or new features outside the agreed defect scope.
